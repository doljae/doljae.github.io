122. Best Time to Buy and Sell Stock II

2021년 5월 27일 · 약 2분
Seokjae Lee
Software engineer

원문: https://doljae.tistory.com/150

1. Greedy​

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        stack = []
        answer = 0
        for price in prices:
            if not stack:
                stack.append(price)
            else:
                if stack[-1] < price:
                    answer+=price-stack[-1]
                    stack.pop()
                    stack.append(price)
                else:
                    stack.pop()
                    stack.append(price)
        return answer
